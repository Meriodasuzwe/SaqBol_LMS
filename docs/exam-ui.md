# Интерфейс пробного тестирования SAQBol

Пользовательский маршрут `/exams` встроен в основное React-приложение и защищён существующим входом. Навигация ведёт на выбор формата, подтверждённый старт, прохождение, отдельный результат и разбор. Это интеграция нового серверного lifecycle, а не копия QuizPage. Старый QuizPage и его маршруты в этом шаге не менялись.

## Путь пользователя

- Выбор формата читает реальные `/exams/configurations/`. Изменение выбора не создаёт попытку. Недоступные форматы показывают причину; полный научно-педагогический режим нельзя запустить на 50 вопросах.
- Подтверждение старта показывает состав, язык, время и максимальные баллы из серверной конфигурации. UUID старта сохраняется для повтора запроса.
- Незавершённые попытки можно продолжить, завершённые — открыть из списка. Пагинация доступна через «Показать ещё».
- Предметная навигация использует метаданные секций, отдельные номера 1–30 и 1–20, последний вопрос каждой секции и реальные ID. Один и тот же номер в разных предметах не смешивает ответы.
- Сохранение выполняется через 650 мс после изменений. Запросы идут последовательно с серверной ревизией. Ответ старого запроса не затирает более свежий выбор. «Сохранено» отображается только после подтверждения API.
- Ошибка сохранения сохраняет выбор в памяти открытой страницы; повтор отправляет прежний UUID и тело запроса, затем сохраняет последующие изменения. Конфликт версии требует явной загрузки сохранённого состояния.
- Перед завершением показываются отвеченные, пропущенные и отмеченные вопросы по предметам. Актуальные ответы передаются в атомарный finish. После неоднозначной ошибки выбор блокируется для безопасного повтора той же сдачи.
- Таймер вычисляется из серверных `deadline` и `server_time`. Истечение времени вызывает чтение серверного результата, а не отправку запоздалых ответов. При скачке часов устройства время сверяется повторно.
- Разбор получает баллы и состояния каждого вопроса из API. Нет второго алгоритма оценивания. Пропуск, неправильный, частичный и полный ответы различаются независимо от общего процента. Отсутствующее объяснение явно обозначено.
- «Сообщить об ошибке» использует существующий `/bugs/`. В описание добавляются только разрешённые ID попытки, предмета, вопроса и путь без query/hash. Ключи и ответы не включаются. Открытие/отправка формы не сбрасывает выбор и не останавливает время.

Маршруты:

- `/exams`
- `/exams/attempts/:attemptId`
- `/exams/attempts/:attemptId/result`
- `/exams/attempts/:attemptId/review`

## Изолированное превью

Из текущей рабочей копии, не из другого checkout:

```powershell
cd C:\Users\User\.codex\worktrees\pr-32-merge\SaqBol_LMS\services\frontend
node tests/runExamPreview.mjs
```

Открыть **http://127.0.0.1:4181/exams**. Если процесс уже работает, достаточно открыть адрес; не запускать вторую копию на том же порту. Остановка своего процесса: Ctrl+C.

Превью отображает настоящий ExamPage и Navbar. Используются реальные JWT, Django URLs, обработчики, ORM и оценивание, SQLite в памяти одноразового контейнера. Docker работает с `--network none`, `--read-only`, tmpfs и разрешённым списком исходников; рабочая БД, `.env`, реальные пользователи и внешние сервисы не подключаются. Требуется уже существующий образ `saqbol_lms-core_service:latest`, скачивание отключено.

Доступен только искусственный набор «Демонстрация двух профильных предметов». Он не публикуется в приложение и не объявляется официальным банком. Панель тестовых сбоев находится отдельно, в закрытом блоке инструментов разработки; её нет в основном приложении. Проверка таймера использует явно тестовую команду установки дедлайна; обычная демонстрация запускается без таймера. Данные исчезают после остановки контейнера.

На обычном localhost этот шаг не развёрнут: рабочие контейнеры не пересобирались и миграции на рабочей БД не применялись. Рабочий профильный режим требует явной привязки подходящего опубликованного набора к серверной конфигурации. Материалы английского и ТГО и полный научно-педагогический режим по-прежнему недоступны.

## Ограничения

Сохранёнными считаются только подтверждённые сервером изменения. Явный выход, обычные ссылки приложения и Logout в активной попытке предупреждают пользователя и ожидают сохранения. Reload/закрытие страницы при несохранённых изменениях вызывают предупреждение браузера. Кнопка Back в существующем BrowserRouter не имеет строгого блокировщика: выполняется попытка сохранения при размонтировании, но при разрыве связи неподтверждённые изменения могут потеряться. Это не выдаётся за гарантированное восстановление.

Фоновое расписание команды завершения просроченных попыток не включалось. Сервер проверяет срок при обращении к попытке; поздние ответы не принимаются. Планировщик для закрытых вкладок остаётся задачей развёртывания.

Учебные тексты и названия предметов приходят на языке материала из API. UI-тексты добавлены для RU/KK/EN; язык интерфейса не объявляет готовность казахского банка.
