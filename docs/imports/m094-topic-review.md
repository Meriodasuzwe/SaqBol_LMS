В исходной спецификации АиСД в описании графов перепутаны сокращения BFS/DFS. При разметке используется название темы, эта опечатка не переносится в вопросы.

Новая версия имеет отдельный package_id. Загружать её можно только в новый пустой черновой Quiz kt_profile без ключа конфигурации. Прежний опубликованный Quiz и его журнал не перезаписываются.

На localhost размеченная версия загружена в Quiz 119 / Course 37 со статусом draft и пустым ключом конфигурации. Она не опубликована и не подменяет действующий Quiz 118. Черновик доступен администратору; в обычном каталоге он не показывается.

Проверено: загрузка пакета в изолированную SQLite без сети, сохранение 43 тем / 7 пустых значений, неизменность исходных вопросов и ответов, повторный импорт без дублей. После загрузки локального черновика dry-run повторно подтверждает совпадение пакета и сохранённых данных.

```powershell
docker exec saqbol_core_service python manage.py import_kt_variant /tmp/m094-topics-v2.json --quiz-id 119 --dry-run
```
