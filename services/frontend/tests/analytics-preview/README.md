# Ручная проверка полного выбора

Стенд использует настоящий QuizPage, api.js, JWT, обработчики Django и ORM.
Создаётся временная SQLite `:memory:` с тремя искусственными SQL-вопросами.
Это техническая фикстура, не проверенный учебный материал КТ.

## Запуск

Нужны работающий Docker, существующий локальный образ
`saqbol_lms-core_service:latest` и установленные frontend-зависимости.
Runner не скачивает образ и не устанавливает пакеты.

Из этой рабочей копии:

```powershell
cd C:\Users\User\.codex\worktrees\pr-32-merge\SaqBol_LMS\services\frontend
node tests/runAnalyticsPreview.mjs
```

Открыть http://127.0.0.1:4179/. Если адрес уже работает, второй экземпляр не нужен.
Ctrl+C останавливает стенд; следующий запуск создаёт чистую искусственную БД.

## Что проверить

1. Ответить на первый вопрос, выбрать два варианта во втором и три в третьем.
2. Нажать «Завершить тест».
3. На этой же странице ниже нажать «Прочитать сохранённые ответы».
4. Сверить полные списки ID и тексты с выбранными вариантами.
   Значения читаются из ORM, а не из состояния React.
5. Можно нажать «Попробовать снова» для другого набора ответов.

Панель диагностики — только инструмент проверки, не реализованная история
попыток продукта. Правила QuizPage не изменены: для сдачи нужно ответить на все
вопросы, переключение вкладок вызывает существующие предупреждения.

## Границы

- Код приложения, валидация и оценивание не подменяются.
- Синтетический вход выполняется преподавателем — владельцем тестового курса,
  без staff/superuser. Это проверка записи выбора, не проверка всех ролей доступа.
- Docker без сети, файловая система read-only, `/tmp` в памяти.
- Рабочие БД, `.env`, внешние сервисы и реальные пользователи не используются.
- JSONL/stdin заменяет только HTTP-транспорт до Django; PostgreSQL и production
  HTTP-сервер этим стендом не проверяются.
- Сохранение результата и аналитики по-прежнему выполняется двумя запросами.
  Связь между ними может отсутствовать; диагностика не подставляет её сама.
- `/__analytics_preview__/state` — локальное чтение синтетических записей.
  Ключи правильных ответов и данные входа эта диагностика не выводит.
