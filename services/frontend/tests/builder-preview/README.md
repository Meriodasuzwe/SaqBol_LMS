# Изолированная проверка конструктора

Из корня репозитория, при уже установленных frontend-зависимостях:

```powershell
cd services/frontend
node tests/runBuilderPreview.mjs
```

Открыть http://127.0.0.1:4177/. Используется настоящий `src/CourseBuilder/CourseBuilder.jsx` с маршрутом `/teacher/course/901/builder` внутри MemoryRouter. Приложение и его маршрутизация не изменяются.

Все данные искусственные: draft-курс 901, урок 902, quiz-шаг 903 и тест 904. Вопросы служат только проверке одиночного/множественного ключа и объяснения, не являются официальными заданиями КТ. Никаких пользователей, авторизации, рабочей БД, `.env` или внешних сервисов нет. Реальный API заменён только в этом runner; CSP блокирует внешние запросы, шрифты и iframe.

Сохранение теста и шага имитируется в памяти процесса. После сохранения нажмите «Повторно открыть», перезагрузите страницу или переключитесь на текстовый шаг и обратно. Обновлённые данные запрашиваются настоящим конструктором. Перезапуск runner сбрасывает фикстуру; кнопка «Сбросить фикстуру» делает это явно.

По адресу http://127.0.0.1:4177/__builder_preview__/state доступны сохранённые синтетические данные и последние 100 запросов с payload. Это помогает проверить полный ключ, explanation и отсутствие запросов после клиентской ошибки. Записи журнала и данные не сохраняются на диск.

Поддерживаются только чтение курса/урока/теста, `POST quizzes/save-generated/` и `PATCH courses/steps/903/` или `905/`. Создание/удаление курсов и шагов, загрузка файлов, публикация, AI и прочие операции намеренно отклоняются. Переход к курсу показывает явно обозначенную заглушку. Установка зависимостей не выполняется.

Это проверка frontend-контракта и повторного открытия, **не проверка backend-валидации, базы, транзакций или истории попыток**. Заглушка лишь преобразует присланные варианты/индексы в форму `choices` для повторного чтения; оценивание не выполняется.
